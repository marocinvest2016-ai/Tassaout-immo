## Comment publier une annonce

Créez un fichier Markdown par annonce dans le dossier `listings/` en suivant le modèle ci-dessous.

### Modèle d'annonce

- Titre : Vente terrain agricole 2 ha — Douar X, Kelaat Sraghna
- Type : Terrain agricole
- Superficie : 2 hectares (20 000 m²)
- Localisation : Douar X, Commune Y, Kelaat Sraghna (coordonnées GPS : 31.XXXX, -7.XXXX)
- Usage : Agriculture / oliveraie / maraîchage
- État : Irrigué / Non irrigué / Clôturé
- Accès : Route goudronnée / piste carrossable / proche route nationale
- Prix : 120 000 MAD (ou prix au m²)
- Photos : ajouter images dans le dossier `images/nom_annonce`
- Documents : titre foncier, certificat, dossier cadastral (indiquer disponibilité)
- Description courte : Terrain plat, sol fertile, puits et source à 500 m, idéal pour exploitation maraîchère.
- Contact : Nom, téléphone, e‑mail (ou lien vers formulaire)

## Bonnes pratiques pour les annonces

- Ajouter au moins 3 photos (paysage, accès, vue générale).
- Indiquer les documents disponibles (titre foncier, certificat, dossier cadastral).
- Indiquer la distance aux commodités (marché, route, eau, électricité).
- Mettre un prix clair (ou "à négocier") et préciser si les visites sont possibles sur rendez‑vous.
